# CloseLid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar app with a one-click switch that keeps a MacBook running with the lid closed (so LLM agents keep working) and switches back to normal sleep.

**Architecture:** SwiftUI `MenuBarExtra` app driving the root-only `pmset -a disablesleep` flag through a one-time, narrowly scoped sudoers rule. A pure `Core/` layer (parsing, command building, sudoers rendering, quit policy) is fully unit tested with fixture strings; a thin `System/` layer does the actual process spawning and IOKit assertion; a `PowerController` orchestrates and always re-reads real system state after every write.

**Tech Stack:** Swift 5 language mode on Xcode 26 / Swift 6.2 toolchain, SwiftUI `MenuBarExtra` + `@Observable` (macOS 14+), XCTest, xcodegen (`/opt/homebrew/bin/xcodegen`), `xcodebuild` from the CLI, IOKit `pwr_mgt`.

**Spec:** `docs/superpowers/specs/2026-09-02-close-lid-design.md`

## Global Constraints

- Deployment target **macOS 14.0**; build with Xcode 26.0.
- Language mode `SWIFT_VERSION = 5.0` (avoids Swift 6 strict-concurrency friction in a tiny app).
- App Sandbox **off**, Hardened Runtime **off**, ad-hoc code signing (`CODE_SIGN_IDENTITY = -`).
- Bundle id `com.alexwang.CloseLid`, product name `CloseLid`, `LSUIElement = true`.
- The only privileged writes are `/usr/bin/pmset -a disablesleep 1|0`, and installing/removing `/etc/sudoers.d/closelid`. Nothing else ever runs as root.
- Sudoers rule is scoped to the **current username only**, never `%admin`.
- Every state shown in the UI comes from re-reading `pmset -g`; never trust a write.
- No `caffeinate`, no IOPMAssertion-only "solutions": they do not stop lid-close sleep. The IOPMAssertion in this plan is an *additional* guard against idle sleep, never the primary mechanism.
- Commit after every task with the message shown in that task.
- All build/test commands run from the repo root `/Users/alexwang/Close_Lid`.

```swift
import Foundation

enum PowerMode: Equatable {
    case normal   // lid close sleeps the Mac (SleepDisabled absent or 0)
    case awake    // SleepDisabled 1: Mac keeps running with the lid closed
    case unknown  // could not read pmset
}

enum PowerSource: Equatable {
    case ac, battery, unknown
}

struct PmsetSnapshot: Equatable {
    var sleepDisabled: Bool?
    var powerSource: PowerSource

    var mode: PowerMode {
        switch sleepDisabled {
        case nil: return .unknown
        case true?: return .awake
        case false?: return .normal
        }
    }
}
```

- [ ] **Step 4: Write `Sources/CloseLid/Core/PmsetParser.swift`**

```swift
import Foundation

/// Pure text parsing of `pmset` output. No I/O.
enum PmsetParser {
    /// Parses `pmset -g` output.
    /// - Returns: `true` if a `SleepDisabled 1` line exists, `false` if the text is
    ///   recognisably pmset output without that flag set, `nil` if the text does not
    ///   look like `pmset -g` output at all.
    static func sleepDisabled(fromSettings text: String) -> Bool? {
        guard text.contains("Currently in use:") else { return nil }
        for line in text.split(whereSeparator: \.isNewline) {
            let fields = line.split(whereSeparator: { $0 == " " || $0 == "\t" })
            guard fields.count >= 2, fields[0] == "SleepDisabled" else { continue }
            return fields[1] == "1"
        }
        return false
    }

    /// Parses `pmset -g batt` output ("Now drawing from 'AC Power'").
    static func powerSource(fromBattery text: String) -> PowerSource {
        if text.contains("'AC Power'") { return .ac }
        if text.contains("'Battery Power'") { return .battery }
        return .unknown
    }
}
```

```swift
import Foundation

/// Renders the single sudoers drop-in this app installs. Pure; no I/O.
enum SudoersRule {
    static let path = "/etc/sudoers.d/closelid"

    enum Error: Swift.Error, Equatable {
        case invalidUsername(String)
    }

    /// Conservative POSIX-style username: starts with a letter or underscore,
    /// then letters/digits/`_`/`.`/`-`, max 32 chars. Anything else is refused so a
    /// crafted username can never inject extra sudoers grammar.
    /// `\z` (absolute end), not `$`: in ICU `$` also matches before a trailing line
    /// terminator, which would let "alex\n" through.
```

```swift
/// Scripted shell for tests. Responses are keyed by the exact argv; each key holds a
/// FIFO queue so the same command can answer differently on successive calls
/// (e.g. probe before/after a toggle). Every call is recorded.
final class MockShellRunner: ShellRunning {
    struct UnexpectedCommand: Error, Equatable { let argv: [String] }

    private var queues: [[String]: [ShellResult]] = [:]
    private(set) var calls: [[String]] = []

    func enqueue(_ argv: [String], _ result: ShellResult) {
        queues[argv, default: []].append(result)
    }

    func enqueue(_ argv: [String], status: Int32 = 0, stdout: String = "", stderr: String = "") {
        enqueue(argv, ShellResult(status: status, stdout: stdout, stderr: stderr))

    func run(_ argv: [String]) throws -> ShellResult {
        calls.append(argv)
        guard var queue = queues[argv], !queue.isEmpty else { throw UnexpectedCommand(argv: argv) }
        let result = queue.removeFirst()
        queues[argv] = queue
        return result
    }
```

```swift
import Foundation

struct ShellResult: Equatable {
    var status: Int32
    var stdout: String
    var stderr: String
}

protocol ShellRunning {
    /// Runs `argv[0]` with `argv[1...]` as arguments, waits for exit, captures output.
    /// Throws only if the process could not be launched.
    func run(_ argv: [String]) throws -> ShellResult
}

struct ProcessShellRunner: ShellRunning {
    func run(_ argv: [String]) throws -> ShellResult {
        precondition(!argv.isEmpty, "argv must contain an executable path")
        let process = Process()
        process.executableURL = URL(fileURLWithPath: argv[0])
        process.arguments = Array(argv.dropFirst())
        let out = Pipe()
        let err = Pipe()
        process.standardOutput = out
        process.standardError = err
        process.standardInput = FileHandle.nullDevice
        try process.run()
        // Drain both pipes concurrently. Reading them one after the other can deadlock:
        // a child that fills the stderr pipe before closing stdout blocks on write while
        // we block reading stdout.
        var errData = Data()
        let group = DispatchGroup()
        group.enter()
        DispatchQueue.global(qos: .userInitiated).async {
            errData = err.fileHandleForReading.readDataToEndOfFile()
            group.leave()
        }
        let outData = out.fileHandleForReading.readDataToEndOfFile()
        group.wait()
        process.waitUntilExit()
        return ShellResult(
            status: process.terminationStatus,
            stdout: String(decoding: outData, as: UTF8.self),
            stderr: String(decoding: errData, as: UTF8.self)
        )
    }
}
```

```swift
import Foundation

enum PrivilegedError: Error, Equatable {
    case cancelled          // user dismissed the admin password dialog
    case failed(String)     // stderr from osascript / the script
}

protocol PrivilegedRunning {
    /// Runs a `/bin/sh` script as root after the system admin-password dialog.
    /// `prompt` is the sentence shown in that dialog; it must name CloseLid and say
    /// what is being changed, because the dialog is otherwise attributed to "osascript".
    func runAsRoot(script: String, prompt: String) throws
}

/// Writes the script to a private temp file and runs it through AppleScript's
/// `do shell script … with administrator privileges`, which shows the standard
/// macOS authentication dialog. Writing to a file avoids any AppleScript string escaping.
struct OsascriptPrivilegedRunner: PrivilegedRunning {
    let shell: ShellRunning

    init(shell: ShellRunning) { self.shell = shell }

    func runAsRoot(script: String, prompt: String) throws {
        let url = FileManager.default.temporaryDirectory
            .appendingPathComponent("closelid-\(UUID().uuidString).sh")
        // Create with 0700 in one step so the file never exists with umask-default
        // permissions, and register cleanup before anything else can throw.
        guard FileManager.default.createFile(atPath: url.path, contents: Data(script.utf8),
                                             attributes: [.posixPermissions: 0o700]) else {
            throw PrivilegedError.failed("could not create temporary script at \(url.path)")
        }
        defer { try? FileManager.default.removeItem(at: url) }

        // temporaryDirectory paths never contain single quotes, so this quoting is safe.
        let appleScript = "do shell script \"/bin/sh '\(url.path)'\" with administrator privileges with prompt \"\(Self.escapeForAppleScript(prompt))\""
        let result = try shell.run(["/usr/bin/osascript", "-e", appleScript])
        guard result.status == 0 else {
            if result.stderr.contains("(-128)") { throw PrivilegedError.cancelled }
            throw PrivilegedError.failed(result.stderr)
        }
    }

    /// AppleScript string literals escape only backslash and double quote.
    static func escapeForAppleScript(_ text: String) -> String {
        text.replacingOccurrences(of: "\\", with: "\\\\")
            .replacingOccurrences(of: "\"", with: "\\\"")
    }
}
```

```swift
/// Belt-and-braces guard against *idle* sleep while Awake mode is on.

        IOPMAssertionRelease(assertionID)
        assertionID = 0
        isHeld = false
    }

    deinit { release() }
}
```

```swift
import Foundation

enum PowerError: Error, Equatable {
    case helperNotInstalled
    case commandFailed(String)
    case readBackMismatch(expected: Bool, actual: Bool?)
    case cancelled
}

/// Orchestrates every interaction with the system. Rule: after any write, re-read
/// `pmset -g` and report *that*; never assume the write succeeded.
final class PowerController {
    private let shell: ShellRunning
    private let privileged: PrivilegedRunning
    private let assertion: SleepAssertionHolding

    init(shell: ShellRunning, privileged: PrivilegedRunning, assertion: SleepAssertionHolding) {
        self.shell = shell
        self.privileged = privileged
        self.assertion = assertion
    }

    /// Reads the live system state and aligns the idle-sleep assertion with it.
    func probe() throws -> PmsetSnapshot {
        let settings = try shell.run(PowerCommand.probeSettings)
        let battery = try shell.run(PowerCommand.probeBattery)
        let snapshot = PmsetSnapshot(
            sleepDisabled: PmsetParser.sleepDisabled(fromSettings: settings.stdout),
            powerSource: PmsetParser.powerSource(fromBattery: battery.stdout)
        )
        syncAssertion(to: snapshot.sleepDisabled)
        return snapshot
    }

    func isHelperInstalled() -> Bool {
        (try? shell.run(PowerCommand.probeHelper))?.status == 0
    }

    /// Flips the flag through non-interactive sudo, then verifies by re-probing.
    @discardableResult
    func setSleepDisabled(_ enabled: Bool) throws -> PmsetSnapshot {
        let result = try shell.run(PowerCommand.setSleepDisabled(enabled))
        guard result.status == 0 else {
            if !isHelperInstalled() { throw PowerError.helperNotInstalled }
            throw PowerError.commandFailed(result.stderr)
        }
        let snapshot = try probe()
        guard snapshot.sleepDisabled == enabled else {
            throw PowerError.readBackMismatch(expected: enabled, actual: snapshot.sleepDisabled)
        }
        return snapshot
    }

    func installHelper(username: String) throws {
        let rule = try SudoersRule.render(username: username)
        try runPrivileged(PowerCommand.installHelperScript(ruleText: rule), prompt: PrivilegedPrompt.install)
    }

    /// Reverts sleep to normal (inside the root script) and deletes the sudoers rule.
    /// `currentlyAwake` only selects the prompt so the user is told about the revert.
    func removeHelper(currentlyAwake: Bool) throws {
        let prompt = currentlyAwake ? PrivilegedPrompt.removeWhileAwake : PrivilegedPrompt.remove
        try runPrivileged(PowerCommand.removeHelperScript, prompt: prompt)
        assertion.release()
    }

    // MARK: - Private

    private func runPrivileged(_ script: String, prompt: String) throws {
        do {
            try privileged.runAsRoot(script: script, prompt: prompt)
        } catch PrivilegedError.cancelled {
            throw PowerError.cancelled
        } catch let PrivilegedError.failed(message) {
            throw PowerError.commandFailed(message)
        }
    }

    private func syncAssertion(to sleepDisabled: Bool?) {
        if sleepDisabled == true { assertion.acquire() } else { assertion.release() }
    }
}
```

```swift
import Foundation
import Observation

@MainActor
@Observable
final class AppState {
    // MARK: Live wiring
    static let shared: AppState = {
        let shell = ProcessShellRunner()
        let controller = PowerController(
            shell: shell,
            privileged: OsascriptPrivilegedRunner(shell: shell),
            assertion: IOPMSleepAssertion()
        )
        return AppState(controller: controller, defaults: .standard, username: NSUserName())
    }()

    // MARK: Observable state
    private(set) var mode: PowerMode = .unknown
    private(set) var powerSource: PowerSource = .unknown
    private(set) var helperInstalled = false
    var lastError: String?

    /// Shows a native alert for failures of user-initiated actions. Injected so tests
    /// record instead of blocking on a modal; the live wiring is in AppDelegate.
    /// Never called from the periodic refresh.
    @ObservationIgnored var alertPresenter: (_ title: String, _ message: String) -> Void = { _, _ in }

    /// Stored (not computed) so Observation tracks it and the menu Toggle re-renders.
    var stayAwakeAfterQuit: Bool {
        didSet { defaults.set(stayAwakeAfterQuit, forKey: Self.stayAwakeKey) }
    }

    private static let stayAwakeKey = "stayAwakeAfterQuit"
    private let controller: PowerController
    private let defaults: UserDefaults
    private let username: String
    private var refreshTimer: Timer?

    init(controller: PowerController, defaults: UserDefaults, username: String) {
        self.controller = controller
        self.defaults = defaults
        self.username = username
        self.stayAwakeAfterQuit = defaults.bool(forKey: Self.stayAwakeKey)
    }

    /// Call once from the app delegate. Keeps the menu roughly current even though
    /// `.menu`-style MenuBarExtra content does not get reliable onAppear callbacks.
    /// The periodic tick only re-reads pmset; it does NOT re-probe sudo, because a
    /// failing `sudo -n -l` writes an auth-failure line to the system log each time.
    func startPeriodicRefresh(interval: TimeInterval = 20) {
        refresh()
        refreshTimer?.invalidate()
        refreshTimer = Timer.scheduledTimer(withTimeInterval: interval, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.refreshPowerOnly() }
        }
    }

    // MARK: Actions

    /// Full refresh: pmset state + helper presence. Used on launch and after actions.
    func refresh() {
        refreshPowerOnly()
        helperInstalled = controller.isHelperInstalled()
    }

    /// Re-reads `pmset -g` / `pmset -g batt` only.
    func refreshPowerOnly() {
        do {
            apply(try controller.probe())
        } catch {
            mode = .unknown
            lastError = "Could not read power settings: \(error.localizedDescription)"
        }
    }

    func toggle() {
        let target: Bool
        switch mode {
        case .normal: target = true
        case .awake: target = false
        case .unknown: return
        }
        do {
            // setSleepDisabled already re-probed and verified; use that snapshot directly.
            apply(try controller.setSleepDisabled(target))
            lastError = nil
        } catch PowerError.helperNotInstalled {
            // The controller already ran `sudo -n -l` and found no rule.
            helperInstalled = false
            fail(Self.toggleAlertTitle, with: PowerError.helperNotInstalled)
        } catch {
            fail(Self.toggleAlertTitle, with: error)
            refreshPowerOnly()
        }
    }

    private func apply(_ snapshot: PmsetSnapshot) {
        mode = snapshot.mode
        powerSource = snapshot.powerSource
    }

    func installHelper() {
        do {
            try controller.installHelper(username: username)
            lastError = nil
        } catch PowerError.cancelled {
            // user dismissed the password dialog; nothing to report
        } catch {
            fail(Self.ruleAlertTitle, with: error)
        }
        refresh()
    }

    func removeHelper() {
        do {
            try controller.removeHelper(currentlyAwake: mode == .awake)
            lastError = nil
        } catch PowerError.cancelled {
            // silent
        } catch {
            fail(Self.ruleAlertTitle, with: error)
        }
        refresh()
    }

    private static let toggleAlertTitle = "CloseLid could not change the sleep setting."
    private static let ruleAlertTitle = "CloseLid could not update the sudoers rule."

    /// Records the error for the menu and raises the alert. User-initiated paths only.
    private func fail(_ title: String, with error: Error) {
        let message = Self.message(for: error)
        lastError = message
        alertPresenter(title, message)
    }

    /// Synchronous on purpose: called from applicationWillTerminate / SIGTERM.
    func prepareForQuit() {
        refreshTimer?.invalidate()
        let sleepDisabled: Bool? = (mode == .awake) ? true : (mode == .normal ? false : nil)
        guard QuitPolicy.shouldRevertOnQuit(sleepDisabled: sleepDisabled, stayAwakeAfterQuit: stayAwakeAfterQuit) else { return }
        _ = try? controller.setSleepDisabled(false)
    }

    // MARK: Messages

    private static func message(for error: Error) -> String {
        switch error {
        case PowerError.helperNotInstalled:
            return "Sudoers rule not installed. Use “Install Sudoers Rule…” first."
        case let PowerError.commandFailed(stderr):
            return "Command failed: \(stderr.trimmingCharacters(in: .whitespacesAndNewlines))"
        case let PowerError.readBackMismatch(expected, actual):
            return "System did not apply the change (wanted \(expected ? "awake" : "normal"), read back \(actual.map { $0 ? "awake" : "normal" } ?? "unknown"))."
        case PowerError.cancelled:
            return "Cancelled."
        default:
            return error.localizedDescription
        }
    }
}
```

```swift
import AppKit

final class AppDelegate: NSObject, NSApplicationDelegate {
    private var sigtermSource: DispatchSourceSignal?

    func applicationDidFinishLaunching(_ notification: Notification) {
        AppState.shared.alertPresenter = Self.presentAlert
        AppState.shared.startPeriodicRefresh()

        // `kill <pid>` / launchd shutdown send SIGTERM, which bypasses willTerminate.
        // Route it through the normal terminate path so the revert still happens.
        // (Force Quit sends SIGKILL and cannot be caught; launch reconciliation covers that.)
        signal(SIGTERM, SIG_IGN)
        let source = DispatchSource.makeSignalSource(signal: SIGTERM, queue: .main)
        source.setEventHandler { NSApplication.shared.terminate(nil) }
        source.resume()
        sigtermSource = source
    }

    func applicationWillTerminate(_ notification: Notification) {
        AppState.shared.prepareForQuit()
    }

    /// LSUIElement apps have no window to attach to, so activate first and wait one
    /// run-loop turn for the menu to finish dismissing; otherwise the alert opens behind
    /// whatever app has focus.
    private static func presentAlert(title: String, message: String) {
        DispatchQueue.main.async {
            NSApp.activate(ignoringOtherApps: true)
            let alert = NSAlert()
            alert.alertStyle = .warning
            alert.messageText = title
            alert.informativeText = message
            alert.addButton(withTitle: "OK")
            alert.runModal()
        }
    }
}
```

- [ ] **Step 3: Write `README.md`**

````markdown
# CloseLid

A tiny macOS menu bar switch that keeps your MacBook running with the lid closed,
so long-running LLM agents (Claude Code, local model servers, …) are not frozen
by sleep. One click on, one click off.

## Why not `caffeinate`?

`caffeinate` and power assertions only stop *idle* sleep. Closing the lid still
sleeps a MacBook. The only software switch that prevents that is the root-only
power-management flag `pmset -a disablesleep 1`. This app flips exactly that flag.

## Requirements

- macOS 14 or later, Apple Silicon or Intel MacBook.
- Xcode 26 and [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`) to build.

## Build

```sh
scripts/build.sh          # produces build/CloseLid.app
open build/CloseLid.app
```

## First run: install the sudoers rule (one admin password, once)

Because `pmset disablesleep` needs root, the app installs a single sudoers
drop-in at `/etc/sudoers.d/closelid` containing only:

```
<your-username> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 1, /usr/bin/pmset -a disablesleep 0
```

The file is validated with `visudo -c` before it is copied into place. Nothing
else is granted. After that, toggling is silent.

Menu → **Install Sudoers Rule…** → enter your password in the system dialog (it names CloseLid and says what it installs).

## Use

| Menu item | Meaning |
|---|---|
| Keep Awake with Lid Closed | Checkmark item; click to toggle. The menu bar icon is a laptop normally and a coffee cup while awake. A laptop with a warning badge means the app could not read the sleep setting. |
| On AC power / On battery — … | Power source. On battery, Keep Awake runs the Mac down to empty, so the line says so in both states. |
| Stay Awake After Quit | By default quitting the app restores normal sleep. Tick this to leave the flag on. |
| Remove Sudoers Rule… | Restores normal sleep and deletes `/etc/sudoers.d/closelid`. The password dialog tells you when this will also switch you back to normal sleep. |

If a toggle fails, CloseLid shows a native alert with the reason, and the same text stays at the top of the menu until the next successful action.

The app always re-reads `pmset -g` after every change and shows what the system
actually reports. If the app crashes while Awake, the flag stays on (macOS
persists it); relaunching shows the true state so you can switch it off.

## Uninstall

1. Menu → **Remove Sudoers Rule…** (admin password).
2. Quit the app and delete `CloseLid.app`.
3. Manual fallback if you skipped step 1: `sudo pmset -a disablesleep 0` and
   `sudo rm /etc/sudoers.d/closelid`.

## Caveats

- A closed MacBook on a soft surface can run hot. Leave it on a hard surface.
- On battery, Awake mode drains until forced shutdown. Plug in.
- Not sandboxed, not notarized, not for the App Store. Built for personal use.
````
